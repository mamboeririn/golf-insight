Golf Insight iPhone PWA v1

GitHub Pagesで公開する手順：
1. GitHubで新しいPublicリポジトリ（例 golf-insight）を作成。
2. このフォルダ内の5ファイル（index.html, manifest.webmanifest, sw.js, icon.png, icon-512.png）をリポジトリのルートへアップロードしてCommit。
3. Settings > Pages > Build and deployment > Deploy from a branch > main / (root) > Save。
4. 公開された https://ユーザー名.github.io/golf-insight/ をiPhoneのSafariで開く。
5. Safariの共有ボタンから「ホーム画面に追加」。

注意：
- ショットデータはiPhoneのブラウザ内に保存。サーバー同期はしません。
- Safariの履歴・Webサイトデータ削除、端末変更、プライベートブラウズでデータが失われることがあります。
- 「データ」タブからJSONバックアップを定期的に保存してください。
- AI分析やApple Watch連携は未実装です。
- GitHub PagesのPublicリポジトリに個人情報や秘密情報をアップロードしないでください。
